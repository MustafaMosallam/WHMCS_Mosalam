# Implementation architecture

- Frontend: Next.js App Router, React and TypeScript in `apps/web`.
- Visual identity: preserved restrained blues, modest server depth and sparse gold geometrical traces. Functional icons remain flat.
- Pages: initial homepage plus cPanel, VPS, VDS, managed cloud and contact placeholder. These are foundations, not production-ready sales pages.
- Product information: no invented live prices, uptime promises, data centers, payment or provisioning.
- Backend separation: WHMCS client/billing APIs will be implemented via server-only adapters, credentials held in environment secrets and tested before use.
- Accessibility: visible focus, reduced motion; dedicated WCAG 2.2 AA audit before launch.
- Next: migrate the remaining information architecture, unique service illustrations, catalog schemas, Arabic RTL, checkout UX, customer portal, testing and deployment.
