# Mosalam UI-first design phase

This repository is for **visual design and front-end behavior only** until the complete public website is approved. Do not add WHMCS integration, payment processing, production login, provisioning, or backend calls.

## Design principles

- Preserve the previously approved clean blue-gradient website, not the overloaded geometric variant.
- Use restrained gold line accents with meaningful visual hierarchy.
- Meaningful flat service pictograms and controlled 3D illustrations; no festival-like architectural hero.
- Fine, low-contrast symmetric/Islamic-geometric background lines; avoid dense full-section faceting.
- Natural short gold electrical pulses can follow background lines, staggered and not synchronized.
- Brief internal route transition; no artificial delay; honor prefers-reduced-motion.
- Complete responsive desktop and mobile experiences before approval.

## Required UI approval scope

Homepage, web/cPanel/WordPress/reseller hosting, VPS, VDS, dedicated servers, cloud, domains, backups, security, infrastructure and solutions, hosting plan comparison, product details, service request flow, support/contact, navigation, footer and responsive states.

Until catalog approval, sample plans must be explicitly labeled illustrative. No invented price, SLA, region, capacity, availability or claim of real transactions.

## Publish preview

This repo is configured for GitHub Pages using a static Next.js export from `apps/web`. Changes to the review branch trigger the Pages workflow.

**One-time GitHub action**: repository **Settings → Pages → Build and deployment → Source: GitHub Actions**. GitHub Pages for private repositories requires an eligible paid plan; a public preview of this site may still be available to anyone with its link. Do not change repository visibility without approval.

After the workflow succeeds and GitHub Pages is enabled, use the actual published URL shown under GitHub **Settings → Pages** or in the workflow deployment result. This configuration does not by itself prove a live site is published.
