# Mosalam vNext implementation

## Design decisions
- Small interface icons are flat; each service has a separate semantic silhouette. Large illustrations receive moderate depth only.
- Islamic geometric motif is in section frames, faceted cuts, repeated tile backgrounds and keyline rhythm rather than sacred text.
- Plan sections are specific to workloads; no made-up numeric specifications or prices.
- Order requests are intentionally a frontend-only design prototype. There is no payment, backend, real quote, provisioning or domain search.
