# Release checklist

- [ ] Confirm which **proposed** product categories Mosalam currently sells.
- [ ] Publish real plan pricing and complete checkout/renewal totals from an authoritative catalog.
- [ ] Confirm cPanel/WHM licenses, exact storage/network quotas, backup coverage and customer support scope.
- [ ] Confirm VDS allocation semantics and provider-specific guarantees; avoid arbitrary claims.
- [ ] Replace concept logo with source-of-truth brand vector and approve geometric patterns/illustrations.
- [ ] Replace dummy portal data with authenticated resource/API calls; threat-model sensitive actions.
- [ ] Integrate payments with approved processor and receipt/tax policies.
- [ ] Integrate verified registrar, contact/ticket backend and real status provider.
- [ ] Publish legally reviewed Terms, Privacy, data processing disclosures and SLA.
- [ ] Complete full English/Arabic translations and bidirectional form handling.
- [ ] Run WCAG 2.2 AA review, keyboard/screen-reader QA, error-message and focus-management QA.
- [ ] Test on iOS Safari, Chrome, Firefox, Edge at mobile, tablet and desktop widths.
- [ ] Implement security headers/CSP, analytics consent, rate limits, input sanitation, logging and incident handling.
- [ ] Evaluate Core Web Vitals, media budgets, caching and optimize SVGs/remote font loading.
- [ ] Validate every action on staging with a real backend and rollback/deployment plan.
