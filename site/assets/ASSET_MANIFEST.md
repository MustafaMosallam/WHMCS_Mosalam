# Mosalam vNext asset manifest

## Editable production-style artwork

- `icons/services/`: 24 individually identifiable flat SVG pictograms, 64x64 artboard. A common stroke, optically distinct symbols.
- `illustrations/solutions/`: 18 standalone SVG large service illustrations. Restrained extrusion, familiar service metaphors, and brand-blue geometry.
- `catalog.json`: mapping of services, illustration names, flat icon names, and proposed tier labels. Tier names are UX proposals, not published offers.

## Cropped references from generated boards

- `concept-crops/icons/`: 20 extracted flat icon PNG crops from the chosen concept board.
- `concept-crops/illustrations/`: 16 large illustration PNG crops from two concept boards.
- `concept-crops/backgrounds/`: 6 concept samples.
- `concept-crops/interaction/`: 5 examples of loading/provisioning/success layouts.

The concept-crops are raster extracts from composite generated images, **not original transparent vector assets**. They may contain antialiasing, generated text and white backgrounds; use them as art direction or in approved light-surface placements, not as trademark-grade vendor logos. For cPanel and WordPress, obtain official permitted logo files and follow each provider’s brand guidelines before any production logo use. The SVG library uses generic semantic pictograms instead.

## UX / purchasing limitation
All tier names are provisional design choices. No prices or concrete server resources are asserted as available. The order configurator is a local request prototype; no order is placed, charged, provisioned, emailed, or stored. Connect a live verified catalog, identity, payment, and order API before offering actual purchasing.
